# みそ帖 Web App

iPhoneで使う前提の、3分類メモアプリです。

## 使い方

1. `index.html` を Safari で開く
2. 右下の共有ボタンから「ホーム画面に追加」する
3. 「設定 / キャラ / テーマ」を選んでメモを書く
4. 保存すると、この端末のブラウザ内にだけ残る

## 保存場所

データはブラウザの `localStorage` に保存されます。

- GitHub には自動で送られません
- ほかの人には見えません
- Safari の閲覧データ削除で消えることがあります

## 書き出し

- Markdown
- テキスト
- HTML（Word で開きやすい形式）
